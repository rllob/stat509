# STAT509 practice quizzes

Spaced-repetition multiple-choice quizzes for STAT 509 (Introduction to Mathematical Statistics,
University of Washington, Autumn 2026), built from my own study guides. One self-contained HTML
file per quiz; progress is saved in the browser.

Live page: https://rllob.github.io/stat509/

Quizzes are generated with a quiz-deck pipeline (YAML question banks → `build_quiz.R`), and this
index with `build_site.R` from `site.yaml`. They contain concepts and practice examples only, no
homework solutions.
